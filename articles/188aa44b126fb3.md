# 概要
Snowflake アカウントをいつくか扱っているとconnections コマンドでアカウントを切り替え忘れたりするので、
起動時に接続先を選択できるスクリプトを用意しました。

## スクリプト

前提条件は以下の通りです。

- `cortex` CLI がインストール済み
- `fzf` がインストール済み
    - `peco` 利用の方は読み替えてください
- `jq` がインストール済み

```zsh
function coco() {
    # 引数に -c/--connection が含まれているかチェック
    local has_connection=false
    local selected_conn=""

    for arg in "$@"; do
        if [[ "$arg" == "-c" || "$arg" == "--connection" || "$arg" == --connection=* ]]; then
            has_connection=true
            break
        fi
    done

    if [[ "$has_connection" == false ]]; then
        local connections=$(cortex connections list | jq -r '.connections | keys[]')
        if [[ -z "$connections" ]]; then
            echo "接続が見つかりません" >&2
            return 1
        fi

        selected_conn=$(echo "$connections" | fzf --reverse --prompt='connection> ')
        if [[ -z "$selected_conn" ]]; then
            echo "接続が選択されませんでした" >&2
            return 1
        fi

        _coco_update_agent_connection "$selected_conn"
        cortex -c "$selected_conn" "$@"
    else
        local next_is_conn=false
        for arg in "$@"; do
            if [[ "$next_is_conn" == true ]]; then
                selected_conn="$arg"
                break
            fi
            if [[ "$arg" == "-c" || "$arg" == "--connection" ]]; then
                next_is_conn=true
            elif [[ "$arg" == --connection=* ]]; then
                selected_conn="${arg#--connection=}"
                break
            fi
        done

        [[ -n "$selected_conn" ]] && _coco_update_agent_connection "$selected_conn"
        cortex "$@"
    fi
}

# settings.json の cortexAgentConnectionName を更新
function _coco_update_agent_connection() {
    local conn="$1"
    local settings_file="$HOME/.snowflake/cortex/settings.json"
    if [[ -f "$settings_file" ]]; then
        jq --arg conn "$conn" '.cortexAgentConnectionName = $conn' "$settings_file" > "${settings_file}.tmp" \
            && mv "${settings_file}.tmp" "$settings_file"
    fi
}
```

## 使い方

使い方はこんな感じです。

```bash
$ coco          → fzf で接続を選んで cortex -c <選択> で起動（対話モード）
$ coco -c ABCD  → そのまま cortex -c ABCD (fzf スキップ)
```
※オプションも指定できるので必要に応じて指定
